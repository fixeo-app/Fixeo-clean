# pSEO Quality Gate V1

The current pSEO corpus is frozen for expansion during the consolidation cutover.

## Purpose

Search Console already shows real value in problem, price and district pages, but also a large zero-click tail. The correct response is selective improvement, not blanket deletion and not more automatic page creation.

## Release gate for any new pSEO URL

A new URL is eligible only when all are true:

1. It owns a distinct search intent.
2. It links clearly to the canonical service × city master.
3. It contains unique, useful information beyond city-name substitution.
4. Its claims are supported by current FIXEO product truth or clearly labelled as indicative.
5. Its canonical URL is clean and unique.
6. It has a documented reason to exist: Search Console demand, business coverage, or a validated user need.

## Current cutover rule

`sitemap-pseo.xml` may not exceed its frozen 391 URLs in this chantier.

Zero-click pages are not automatically noindexed. They are classified later using impression volume, position, query fit, duplication and business value.
